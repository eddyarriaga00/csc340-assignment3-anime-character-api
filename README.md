# Anime Character API

Spring Boot CRUD API for CSC 340 Assignment 3. This backend matches the anime character theme used in Assignment 2 and stores character data in PostgreSQL with Spring Data JPA.

## Installation

1. Clone the repository.
2. Open the project in VS Code.
3. Add your Neon Java connection string to `src/main/resources/application.properties`.
4. If your JDBC URL does not already include credentials, set `SPRING_DATASOURCE_USERNAME` and `SPRING_DATASOURCE_PASSWORD` before starting the app.

5. Run the command below so Git stops tracking your database password after you update the config file:

```bash
git update-index --skip-worktree src/main/resources/application.properties
```

6. Start the API:

```bash
./mvnw spring-boot:run
```

The API runs at `http://localhost:8080`.

## Character Model

Each character includes these fields:

- `characterId` - autogenerated unique ID
- `name` - character name, required
- `description` - summary of the character, required
- `series` - anime series, required
- `category` - character category such as Hero, Anti-Hero, or Slayer, required
- `signatureAbility` - power or signature move, required

## API Endpoints

### Get all characters

- Method: `GET`
- URL: `/characters`

### Get a character by ID

- Method: `GET`
- URL: `/characters/{id}`

### Add a new character

- Method: `POST`
- URL: `/characters`
- Request body:

```json
{
  "name": "Satoru Gojo",
  "description": "A powerful sorcerer and teacher from Jujutsu High.",
  "series": "Jujutsu Kaisen",
  "category": "Hero",
  "signatureAbility": "Limitless"
}
```

### Update an existing character

- Method: `PUT`
- URL: `/characters/{id}`
- Request body:

```json
{
  "name": "Ken Kaneki",
  "description": "A half-ghoul trying to protect the people on both sides of the conflict.",
  "series": "Tokyo Ghoul",
  "category": "Anti-Hero",
  "signatureAbility": "Kagune"
}
```

### Delete an existing character

- Method: `DELETE`
- URL: `/characters/{id}`

### Get all characters in a category

- Method: `GET`
- URL: `/characters/category/{category}`
- Example: `/characters/category/Hero`

### Search for characters whose name contains a substring

- Method: `GET`
- URL: `/characters/search?name=substring`
- Example: `/characters/search?name=nar`

## Notes

- The application seeds five starter anime characters automatically the first time the database is empty.
- Missing required fields return `400 Bad Request`.
- Requests for a character ID that does not exist return `404 Not Found`.
